Three algorithmic challenges: Dynamic Programming, Greedy Simulation, and Code Debugging.

Task 1 • Dynamic Programming Medium

House Robber Problem

Given an integer array nums representing the amount of money of each house, return the maximum amount of money you can rob tonight without alerting the police (cannot rob adjacent houses).

Example: nums = [2,7,9,3,1]

Output: 12 (Rob house 1 (money = 2), house 3 (money = 9) and house 5 (money = 1). Total = 2 + 9 + 1 = 12)

Task 2 • Greedy Simulation Medium

Predicting the Winning Party (Dota2 Senate)

In the world of Dota2, there are two parties: Radiant and Dire. The Senate consists of senators from both parties. Each senator can ban one senator's rights or declare victory when all remaining are from the same party.

Example: senate = "RD"

Output: "Radiant" (The first senator from Radiant bans the next Dire senator, leaving Radiant as the winner)

Task 3 • Debugging Challenge Debugging

Count Elements Greater Than the Median

Fix flawed logic calculating the count of elements strictly greater than the statistical median in unsorted integer lists of both odd and even parity lengths.

Example: arr = [1, 3, 2, 5, 4]

Sorted: [1, 2, 3, 4, 5] • Median = 3 • Elements > 3: [4, 5] → Count = 2
