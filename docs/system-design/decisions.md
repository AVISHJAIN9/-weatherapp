# Master Design Decisions Log (ADR)

This Architectural Decision Record (ADR) log documents every major technical decision made across the codebase and distributed system design, articulating the options considered, deciding factors, and accepted trade-offs.

---

## Complete Design Decisions Matrix

| Decision ID | Decision Topic | Chosen Option | Alternatives Considered | Deciding Factors | Trade-off Accepted | Revisit When |
| :--- | :--- | :--- | :--- | :--- | :--- | :--- |
| **ADR-01** | **Implementation Runtime** | **Python 3.10+ (Standard Library)** | C++20, Rust, Go, Java 21 | Rapid implementation speed; zero boilerplate; C-level deques and Timsort | Slower raw CPU cycle throughput compared to native C++ binaries | Code is ported to nanosecond HFT or bare-metal execution engines |
| **ADR-02** | **Dynamic Programming Memory Model** | **Two Rolling Scalar Registers (`prev1`, `prev2`)** | Full 1D array (`dp = [0]*n`), Recursion with `@lru_cache` | Reduces auxiliary space from $O(N)$ to $O(1)$; eliminates heap reallocations; CPU cache register locality | Cannot reconstruct the exact sequence of robbed houses (only yields optimal scalar sum) | Problem requires returning the specific indices of robbed houses |
| **ADR-03** | **Queue Structure for Turn Simulation** | **`collections.deque` with $+n$ Index Offsets** | Python `list` (`pop(0)`), Singly-linked list, `queue.Queue` | $O(1)$ popleft and append in C; avoids $O(N^2)$ list shifting; preserves circular round order | Cannot access elements by arbitrary random index in $O(1)$ | Senator voting order requires mid-queue priority jumps |
| **ADR-04** | **Median Finding Strategy** | **In-Place CPython Timsort (`nums.sort()`)** | QuickSelect ($O(N)$), Min-Max Heaps, `statistics.median` | Standard library C-speed; single line of code; predictable $O(N \log N)$ worst-case | $O(N \log N)$ runtime is asymptotically inferior to $O(N)$ QuickSelect | Array lengths exceed $10^7$ elements and sorting becomes a bottleneck |
| **ADR-05** | **Even-Length Median Definition** | **Floor Integer Index (`len // 2`)** | Floating-point mean of middle two elements | Problem demands integer discrete element comparison; conforms to competitive programming standards | Deviates from continuous mathematical statistical median definition | Problem specification explicitly mandates floating-point averages |
| **ADR-06** | **Distributed Code Judge Architecture** | **Event-Driven Microservices (Queue-Decoupled)** | Monolith, Synchronous REST Microservices, Serverless Lambda | Complete fault isolation; student code crashes do not bring down API; absorption of traffic bursts | Higher operational and infrastructure deployment complexity | System receives $< 100$ submissions per day |
| **ADR-07** | **Job Queue Broker** | **BullMQ on Redis 7.2** | Apache Kafka, RabbitMQ, AWS SQS | Sub-millisecond dispatch latency; native priority queues; built-in Redis connection reuse | In-memory message storage requires careful RAM monitoring | Message retention requirements exceed 7 days |
| **ADR-08** | **Worker Execution Sandboxing** | **Google gVisor (`runsc`)** | Raw Chroot, Docker (`runc`), Firecracker MicroVMs | User-space Linux kernel intercepts all syscalls; defense-in-depth against host compromise | 20–50ms container startup overhead | Submissions require bare-metal GPU acceleration |
| **ADR-09** | **Primary Database Engine** | **PostgreSQL 16** | MongoDB, MySQL, CockroachDB, DynamoDB | Strict ACID compliance; rich JSONB support for test logs; GIN full-text search indexes | Single-leader writes require connection pooling via PgBouncer | Global multi-master active-active writes are mandated |
| **ADR-10** | **Test Case Asset Storage** | **Object Storage (S3) + Local RAM Disk (`/dev/shm`)** | PostgreSQL BLOB columns, Local worker SSD | Prevents database table bloat; allows instant zero-copy in-memory test execution on workers | Requires worker cache synchronization step on startup | Test cases are $< 1\text{ KB}$ each |
| **ADR-11** | **Documentation Engine** | **VitePress (Vue.js Docs Standard)** | Docusaurus, MkDocs, GitBook | Official Vue.js documentation tool; instant Vite HMR; native Mermaid diagram plugin; client-side search | Built on Vue ecosystem rather than React | Team mandates React-based MDX plugins |
| **ADR-12** | **Dark Theme Aesthetic** | **Pure Black (`#000000`) High-Contrast** | Standard Gray Dark Theme, Default Light Theme | Superior contrast on OLED displays; sleek, modern developer aesthetics | Requires explicit border contrast tuning for tables and diagrams | Brand guidelines enforce specific corporate palettes |
